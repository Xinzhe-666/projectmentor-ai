# ProjectMentor AI Roadmap

## 已完成

- Spring Boot 3 后端基础工程。
- Vue 3 前端基础页面。
- 用户注册、登录、JWT 鉴权和 BCrypt 密码加密。
- 项目创建、列表、详情和删除。
- README 粘贴保存。
- ZIP 上传、多文件解析和安全过滤。
- README 风险规则扫描。
- 证据链展示。
- 项目审计报告生成。
- OpenAI-compatible AI 审计增强接口。
- AI 不可用时降级为规则版报告。
- AI 幻觉检测。
- 规则版模拟面试 V1。
- 额度账户、额度流水、报告消耗额度和失败返还。
- 异步分析任务和 Redis 进度缓存。
- Docker Compose + Nginx 部署。
- README 和演示文档整理。

## 进行中

- 规则库继续补充，提升对常见 README 夸大表达的识别覆盖。
- 审计报告文案继续调整，让建议更适合简历和面试场景。
- 演示流程继续打磨，补充更清晰的测试项目和截图。
- 面试深挖问题库继续扩展，减少固定模板感。
- AI 增强输出结构继续校验，降低返回内容不稳定带来的影响。

## 计划中

- LLM 深度增强：更稳定的结构化报告、提示词优化和多模型适配。
- RAG 项目问答：基于上传项目文件做检索增强问答。
- PDF 导出：导出审计报告、简历建议和面试复盘。
- 管理员后台：管理用户、额度、任务和报告。
- 线上部署：补充域名、HTTPS、日志和部署说明。
- 用户反馈收集：记录用户对风险识别和建议内容的反馈。
- 更完整的演示素材：补充截图、样例项目和标准演示脚本。
