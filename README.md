# ProjectMentor AI

AI 时代的学生项目真实性审计、简历优化与面试深挖平台。

## 项目定位

ProjectMentor AI 面向计算机学生和后端实习求职者，帮助用户审计自己的项目 README、技术栈、代码结构、安全风险和面试风险，降低 AI 夸大、简历翻车和面试被问穿的概率。

## 当前进度

- 后端基础工程搭建完成
- 统一 Result 返回完成
- 全局异常处理完成
- 健康检查接口完成
- 用户注册 / 登录完成
- JWT 鉴权完成
- BCrypt 密码加密完成
- 注册默认赠送 3 次分析额度完成
